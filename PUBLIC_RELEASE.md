# Publication Notes

Initial public-source candidate extracted from a local research workspace.
Includes source, tests, synthetic fixtures, default configuration and scripts.
Personal research outputs, downloaded market caches, account data and local
development history are not published. README references to excluded historical
reports are not evidence distributed with this release.

Use the offline demo provider for a first run. This is a research/backtesting
tool, not an automated broker or a promise of investment returns. Live public
data retrieval is optional, network dependent and separate from offline tests.
See VALIDATION.md for the checks performed on this source snapshot.
